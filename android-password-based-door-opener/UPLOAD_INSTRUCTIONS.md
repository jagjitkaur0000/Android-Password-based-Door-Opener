# Uploading this repository to GitHub

1. Create a **public** repository named `android-password-based-door-opener` in your GitHub account.
2. Unzip this archive. Open the extracted `android-password-based-door-opener` folder.
3. In GitHub, select **Add file → Upload files** and upload the **contents** of that folder, keeping `report/` and `docs/` folders intact.
4. Commit the files and confirm that `README.md` is shown on the repository homepage.
5. Open `report/Android_Password_Based_Door_Opener_Final_Year_Report.pdf` and copy its public GitHub URL for the Hildesheim application field **Link to the full document**.
